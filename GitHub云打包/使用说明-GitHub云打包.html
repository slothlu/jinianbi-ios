iOS 云打包 + 轻松签安装教程

不需要 Mac、不需要花一分钱，约 30 分钟搞定
原理一句话：GitHub 的服务器上有现成的 Mac + Xcode，免费帮你把扩展 zip 打包成 .ipa，然后用「轻松签」在你自己的 iPhone 上签名安装。全程不碰 Mac、不花一分钱。

本文件夹里有什么

路面纪念钞币科技-Safari.zipiOS 版扩展包（已取消卡密），要上传到 GitHub 的原料
.github/workflows/build-ipa.yml一键打包脚本，GitHub 会照着它自动打包

第 0 步：注册 GitHub 账号（10 分钟，免费）

0 电脑浏览器打开 github.com，点 Sign up，用邮箱注册并设置密码； 按提示完成验证（如收不到邮件，检查垃圾箱；网页打不开就换个浏览器或网络试试）。
重要：下面的仓库必须建为 Public（公开）。GitHub 的免费 Mac 打包额度只对公开仓库生效， 私有仓库用 Mac 打包会按分钟收费。你的插件代码本来就在发给客户的 zip 里，仓库公开不增加额外泄露。

第 1 步：新建仓库（Public）

1 登录后点右上角 「+」→ New repository：
· Repository name 填 jinianbi-ios；
· 选 Public（必须，见上方警告）；
· 其他不用动，点绿色 Create repository。

第 2 步：上传两个文件

2 在新仓库页面点 「Add file」→「Upload files」，把本文件夹里的 「路面纪念钞币科技-Safari.zip」 和 「.github」文件夹 一起拖进页面（拖入 .github 文件夹会自动带上 workflows 子目录）， 然后点绿色 Commit changes。
如果拖文件夹后看不到 .github/workflows/build-ipa.yml（文件列表里要能看到这两行路径）， 改用另一种方式：点 Add file → Create new file，文件名栏手动输入 .github/workflows/build-ipa.yml，把脚本文件里的内容全部复制粘贴进去，再 Commit。

第 3 步：点按钮开始打包

3 仓库页面顶部点 「Actions」 标签 → 左侧点 「打包iOS版-生成未签名IPA」 → 右侧点 「Run workflow」 → 绿色按钮。等 5–10 分钟，页面顶部会出现一个转圈的黄色圆点（正在打包）。
4 打包完成（圆点变绿色 ✓）后，点进这次运行记录，页面底部 Artifacts 区域会出现 LuMianJiNianBi-iOS-unsigned-IPA，点它下载（下载下来是个 zip，解压后里面就是 .ipa 文件）。

第 4 步：传到 iPhone，用轻松签安装

5 把 .ipa 文件通过微信/QQ 文件传输、网盘或数据线发到 iPhone。
6 在 iPhone 上安装 轻松签：浏览器打开轻松签官网（如 quwan.store）， 按页面提示先安装描述文件、再安装轻松签 App；装好后到 设置 → 通用 → VPN 与设备管理 信任对应描述文件。
7 打开轻松签，把 .ipa 导入（微信收到的文件可用「用其他应用打开」→ 轻松签）， 选择 签名 → 选 「Apple ID 签名」并登录自己的 Apple ID（或用你自己的证书签名）→ 签名完成后点安装。
免费 Apple ID 签名的 App 每 7 天失效一次，到期后重新打开轻松签，对已装的 App 重新签一次即可，不用再打包。

第 5 步：启用扩展并使用

8 安装完成后到 设置 → Safari 浏览器 → 扩展，找到 「LuMianJiNianBi」（或中文名「路面纪念钞币科技」），打开开关。
9 打开银行预约页面，点地址栏左侧 「aA」 → 「请求桌面网站」（每次都要）， 悬浮窗出现后点人员姓名即自动识别验证码、填表并提交；按住悬浮窗顶部蓝色标题栏可拖动。

常见问题

Q：Actions 打包失败，显示红叉？
A：点进失败的那次运行，点开红色的步骤，把日志页面截图发给我，我帮你改脚本。常见原因是文件没传全或网络问题。

Q：会不会扣我的钱？
A：只要仓库是 Public 就不会扣钱。如果 Actions 页面提示需要开启账单/billing，说明仓库建成了 Private，改回 Public 即可。

Q：以后更新插件怎么办？
A：把新的 路面纪念钞币科技-Safari.zip 上传覆盖仓库里的旧文件，再到 Actions 里点一次 Run workflow，重新下载新 IPA。

Q：装好后设置里找不到扩展？
A：确认描述文件已信任；在「设置 → Safari → 扩展」里打开开关；打开银行网站时 Safari 弹出授权提示要选「允许」。

Q：没有悬浮窗 / 点人名没反应？
A：必须用「aA → 请求桌面网站」，并确认是支持的银行官网预约页面，然后刷新。

Q：免费 Apple ID 签名 7 天过期，客户怎么办？
A：长期给客户用建议使用证书签名（个人/企业证书，有效期长）；7 天方案适合自用测试。
